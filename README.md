# 数学小练习 (Math Quiz)

为小朋友在 iPad 上做的互动数学练习单页应用。

## 题目设置

- 共 10 题：6 道乘法（最大到 12×12）、2 道三位数加法、2 道三位数减法
- 限时 10 分钟，超时弹窗提醒并继续正向计时（+mm:ss）
- "New quiz" 重新出题；"Check answers" 批改并对错题给出 **错因诊断 + 正确解法**
- 自适应出题：错过的乘法事实会按权重在下次 quiz 中加倍出现（间隔重复）；加减法按"进位/借位"难度分桶并按弱点偏向出题
- 错题立即重练：Check 后可一键「Retry missed」只练刚才做错的题（不计入历史/连胜，只强化事实记忆）
- 弱项专攻：📊 面板里「Practice these now」一键出一组最弱的题
- 渐进课程：当掌握 40 个乘法事实后自动解锁**两位数 × 一位数**范畴，先弹 CRA 教学短课（面积模型：23×4 拆成 20×4 + 3×4），错题诊断会指出"只乘了个位/十位/忘了相加/进位失误"；作为"技能"按整体准确率+流利度追踪
- 渐进课程：当掌握 50 个乘法事实后自动解锁**分数入门**范畴（CC 三年级：分母 2/3/4/6/8）——三种题型：看图说分数（涂色条）、等值分数（1/2 = ?/4）、比较大小（< = >）；CRA 教学短课用分条讲"几分之几"、等值、比较；错题诊断（上下颠倒、忘了同乘、比较规则）
- 渐进课程：当掌握 24 个乘法事实（流利）后自动解锁**除法**范畴，先弹 CRA 教学短课（具体🍪→图示→抽象，并讲"除法是乘法的逆运算"），再开始练习；除法事实按乘法家族用同一套间隔重复引擎追踪；错题有除法专属诊断（误用乘法/减法、找错商等）和「Teach me this」AI 讲解
- 学前小贴士：复习题（曾做错的乘法）作答前会显示一句策略提示（如 ×9、拆十、加倍法）
- AI 讲题：错题诊断里有「🧠 Teach me this」，调用混元生成孩子能懂的趣味讲解（需后端，见下）
- 界面与 AI 输出均为英文

### 学习科学增强（参考 FSRS / BKT / Dweck / CRA / 专长反转 / 85% 规则）
- **闭环难度控制（85% 规则）**：按"模型掌握度 × 课程覆盖率"分档（novice→expert）分配各范畴题量；再用**最近 5 次真实答对率**纠偏——低于 70% 自动降档、高于 93% 升档，模型漂移不再影响体验
- **课程顺序引入新口诀**：新口诀按真实教学顺序（×2→×5→×10→×3/×4→难区→×11/×12）以每卷 1 题的"前沿槽位"稳步引入，新手不会被随机新题淹没
- **分题型流畅度阈值**：单口诀 6s、除法 8s、两位数乘 25s、分数 15s——多步题不再因"不够快"被永久卡在非流利
- **错题日志 + 错误模式识别（全领域）**：每道错题的**原始答案**入库（跨设备同步），自动识别系统性模式——乘法混淆对（6×7 答成 48 = 和 6×8 混）、除法鹦鹉学舌/差一错、加减法与两位数乘"恰好差 10"（进位/借位漏了）、分数上下颠倒、"分母大就大"误概念。识别结果进家长面板、打印报告和 AI 计划,检测到混淆对时专项练习会把**两个口诀并排编入**（对比练习）
- **脚手架感知掌握度**：带提示答对的记忆稳定度增长减半且不给流畅度学分——裸答对才算真掌握
- **过程表扬**：总结文案夸努力与策略、不夸"聪明"、不说"很简单"；并点名"你以前错过、现在做对了"的事实，把进步归因于练习
- **渐隐范例 + 填空题**：已掌握的事实答错只给一行提醒（避免专长反转的冗余），新手给完整竖式；两位数乘法在学习期约半数题以"部分积填空"形式呈现，掌握后自动撤掉脚手架
- **BKT 校准掌握度**：每个事实用贝叶斯知识追踪维护一个 P(掌握) 概率（slip/guess 建模），面板显示各范畴"掌握%"进度条（解锁仍用稳定的 accurate 计数）
- **儿童版进步视图**（🌱）：鼓励性开放学习者模型——各技能成长阶段（🌱→🌿→🌳→⭐）+ 掌握进度条；引擎标注"⭐ Today's pick"（最弱范畴高亮为默认推荐,其余仍可选——引导默认、保留自主）；"这周长了多少"增量行；🗺️ **口诀地图**（121 格按掌握状态着色,看着地图变绿）；解锁进度条（"⚡ 24/40 还差 16 个"）；分数三子技能（认名/等值/比较）独立追踪并显示状态芯片
- 每日连胜（🔥 streak）：连续天数完成 quiz 显示火苗；有 1 天宽限；**跨设备同步会用合并后的答题历史把两台设备各持一半的连胜链重新接起来**
- 📊 Progress 面板：累计数据、最近 10 次柱状图、**🔁 错误模式**（误概念排最前）、**📈 每周快照**（自动滚动 26 周,含与上周对比和掌握度趋势图）、**📚 AI 计划历史**（保留 12 份,不用重复花 API 费）、**🖨️ 打印进度报告**（含各范畴、弱项、错误模式、周趋势,可直接给老师）

### 可靠性
- **断点续答**：每次作答即快照到 localStorage,刷新/误关/崩溃后原样恢复（题目、答案、计时）；12 小时后过期
- **版本可见 + 温和更新**：页脚显示 `Math Quiz vN · updated 日期`;每次启动检查新版本,就绪后显示 "🔄 Update ready" 按钮（不自动刷新,不打断做题）;发版用 `./release.sh` 一键同步版本号/日期/SW 缓存名
- **答题声音反馈（可选）**：顶栏 🔊/🔇 开关,默认关;Web Audio 合成,满分琶音/答对小钟/温和低音,不惩罚

## ✨ AI 学习计划（需要后端 + API key）

📊 Progress 面板里有「生成本周分析和下周计划」按钮。点击后会把孩子本地累积的统计（弱项乘法事实、加减法各难度准确率、除法/两位数乘/分数各范畴进度、**错误模式识别结果**、连胜、最近成绩）发到一个 serverless 函数 `api/plan.js`，由**腾讯混元**大模型生成一份面向家长的分析 + 下周练习计划——计划会按名点出混淆对/误概念并给对症练法。生成过的计划自动留档（📚 Past plans,最多 12 份）。

> 隐私提醒：用这个功能时，孩子的练习统计会发送到服务器端再转发给混元 API。不用这个按钮时，所有数据仍只存在本地。

### 获取腾讯混元 API key

1. 登录腾讯云 https://cloud.tencent.com → 搜索并开通「混元大模型」服务
2. 在混元控制台 → API 密钥管理，创建一个 **OpenAI 兼容接口**的 API key（形如 `sk-...`）
3. 按量付费充值（混元 turbo 很便宜，生成一份计划只需几厘钱）

### 部署步骤（Vercel）

1. 部署仓库到 Vercel（见下方「部署到 Vercel」）—— `api/plan.js` 会被自动识别为 serverless 函数。
2. 在 Vercel 项目 → Settings → Environment Variables 添加：
   - `HUNYUAN_API_KEY` = 你的混元 API key
3. 重新部署。完成后「生成计划」按钮即可用。

可选环境变量：
- `HUNYUAN_MODEL`（默认 `hunyuan-turbo`）—— 也可设为 `hunyuan-pro`、`hunyuan-turbos-latest` 等（以混元控制台支持的模型列表为准）
- `HUNYUAN_BASE_URL`（默认 `https://api.hunyuan.cloud.tencent.com/v1`）—— 如官方接口地址有变可覆盖

本地开发：用 `npx vercel dev` 起本地服务器（需要先设置 `HUNYUAN_API_KEY` 环境变量）；直接开 `index.html` 时除 AI 计划外的功能都可用。

## ☁️ 多设备同步（家庭码 + Upstash）

进度默认存在每台设备本地（localStorage）。开启云同步后，在每台设备的 📊 面板里输入**同一个家庭码**，进度就会跨设备共享（拉取 → 合并 → 回写）。

- 合并策略：每个事实/技能以「最近练过的一侧」为准且练习次数不回退；历史/快照/计划/错题日志按键去重合并；连胜用合并后的答题历史**重算连胜链**（两台设备各打一半也能接上）。单个小孩为主、一台设备时就是简单的「打开拉取、做完上传」。
- 安全：知道家庭码的人都能读到进度，请用别人猜不到的码（≥3 位，字母/数字/`-`/`_`）。

### 开通 Upstash（免费）

1. Vercel 项目 → **Storage** → 选 **Upstash** 的 Redis（Marketplace 一键创建，免费额度足够）
2. 创建后 Vercel 会**自动注入**环境变量 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN`（也兼容 `KV_REST_API_URL`/`KV_REST_API_TOKEN`）
3. **Redeploy** 一次。之后 📊 面板的「多设备同步」就能用了

不配置 Upstash 也不影响其它功能——只是同步按钮会提示未配置。

## PWA：当作 App 用

- iPad Safari 打开网址 → 分享 → "添加到主屏幕"
- 之后从主屏图标启动是全屏无浏览器栏，**离线可用**（service worker 缓存了所有静态资源）
- 所有数据都存在 iPad 本地（localStorage），不上传任何服务器

## 错因诊断举例

- 乘法：相邻乘法表混淆（7×7 vs 7×8）、加减法当成乘法、漏加一项、数字反写等；并给出乘法策略（如 `×9 = ×10 − 自身`）
- 加法：忘记进位、多/少进位、做成减法
- 减法：没借位（取绝对值）、被减数减数颠倒、做成加法、多/少借位
- 每道错题都附上完整 **竖式计算步骤** 教正确解法

## 本地预览

直接在浏览器打开 `index.html` 即可，没有任何依赖。

或起一个本地服务器：

```bash
python3 -m http.server 8080

```

## 部署到 Vercel（免费）

### 方法 A：用 GitHub 一键部署（推荐，最省事）

1. 把这个仓库 push 到 GitHub（已经在 `claude/math-quiz-app-7CzcR` 分支）
2. 打开 https://vercel.com/new
3. 用 GitHub 登录，选择这个仓库 → Import
4. Framework Preset 选 **Other**（纯静态），其他全部默认，点 **Deploy**
5. 30 秒后会拿到一个 `https://xxx.vercel.app` 链接，把链接加到 iPad 主屏幕（Safari → 分享 → 添加到主屏幕）就能像 App 一样用

### 方法 B：用 Vercel CLI

```bash
npm i -g vercel
vercel            # 第一次会让你登录、确认项目
vercel --prod     # 部署到正式环境
```

### 其他免费选项

- **Cloudflare Pages**：https://pages.cloudflare.com/ 同样把仓库连上即可
- **GitHub Pages**：在仓库 Settings → Pages 选 `main` 分支即可（但需要先合并到 main）
- **Netlify Drop**：https://app.netlify.com/drop 把整个文件夹拖进去就部署
